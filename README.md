# Infinity Customizations 🎁✨

> Personalized gifts, polaroids, hampers, custom phone cases, frames, and curated memories handcrafted with love.

---

## 🌟 Overview
Infinity Customizations is a modern, full-featured e-commerce platform offering premium personalized gifting experiences. Customers can discover custom gifts, select variants, place orders with seamless UPI or online checkout, and personalize their orders directly via WhatsApp.

---

## 🚀 Key Features

- **Cinematic 60fps Experience**: Premium gift hamper intro transition that glides seamlessly into a 3D perspective hero carousel.
- **Dynamic Horizontal-8 Infinity Loader**: Bespoke horizontal figure-8 (`∞`) SVG loader across image loads and catalog transitions.
- **Modern Typography**: High-legibility **Manrope** typography with refined typographic scale and letter-spacing across all components.
- **Direct WhatsApp Personalization Flow**: Instant WhatsApp ordering and personalization handoff to `+91 89859 93948` with prefilled order references, product variants, and photo guides.
- **Universal UPI Payments**: Pay seamlessly via any UPI app (GPay, PhonePe, Paytm, etc.) with real-time dynamic UPI intent generation and QR codes.
- **Customization Options**: Polaroid photo packs, custom Spotify plaques, phone cases with model selector, preserved flower bouquets, and vintage frames.
- **Admin Dashboard**: Comprehensive order tracking, product management, phone model catalog, and live analytics.

---

## 🛠️ Tech Stack

- **Frontend**: React (Vite), TailwindCSS, Lucide Icons, Canvas Confetti
- **Backend**: Node.js, Express.js
- **Database**: MongoDB (Mongoose)
- **Deployment**: Vercel ready (`vercel.json`)
